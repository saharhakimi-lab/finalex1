תרחיש ארכיטקטורה רב-סניפית (Multi-Site Enterprise)

הקמת תשתית תקשורת מורכבת בין שני סניפי ארגון

עליכם לחבר ולנתב בין סניף א' (HQ) לבין סניף ב' (Branch). סניף ב' כולל שלוש רשתות סטטיות חדשות (VLAN 40, 50, 60). שני הסניפים מקושרים בכבל שדרתי מהיר של 1 Gbps, ונדרש להגדיר ביניהם ניתוב סטטי או פרוטוקול ניתוב דינמי OSPF Area 0!

משימה 4: הגדרת ניתוב סטאטי ופרוטוקול OSPF

כדי לאפשר תקשורת מלאה בין שני הסניפים דרך קישור ה-1Gbps, ניתן לבחור בין ניתוב סטטי לניתוב דינמי OSPF:

אופציה א': ניתוב סטאטי (Static Route) ב-R1 לסניף ב'

בחר את הפקודה המפנה את כל התעבורה לרשתות סניף ב' (10.0.0.0/16) דרך כתובת הראוטר השני (10.0.0.2):

אופציה ב': ניתוב דינמי OSPF Area 0

פקודות הפרסום של הרשתות המקומיות והשדרתיות בתוך תהליך OSPF Process 1:

Router(config)# router ospf 1

Router(config-router)# network 192.168.0.0 0.0.255.255 area 0

Router(config-router)# network 10.0.0.0 0.255.255.255 area 0
